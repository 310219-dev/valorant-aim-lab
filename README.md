# 角度實驗室

Valorant 靈感的瀏覽器瞄準訓練原型，包含定點急停、轉點反應與預瞄清角練習模式。此專案為獨立練習工具，並非 Riot Games 官方產品，也不會操作遊戲客戶端。

## 本機預覽

直接在瀏覽器開啟 `index.html` 即可。網頁不需要建置步驟。

## 發布

推送到 `main` 分支時，GitHub Actions 會將靜態頁面發布到 GitHub Pages。也可以從 Actions 頁面手動執行 `Deploy to GitHub Pages`。

第一次部署前，請在 GitHub 專案設定中將 Pages 的 Build and deployment source 設為 GitHub Actions。
